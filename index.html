📖 APIキーはどこから取る？（iPhoneで3分・かんたん手順）

手順①：Fal.ai にログインする 下の青いボタンを押して Fal.ai 公式ページ を開き、Googleアカウント（またはGitHub / メール）でログインします。 🌐 1. Fal.ai キー発行ページを開く ↗
手順②：クレジット（残高）を少しチャージする 月額固定費ではなく、使った分だけ減るプリペイド式です。Billing（支払い設定）ページでクレジットカード等を登録し、まずは $5〜$10（約750円〜1,500円） ほどチャージします。 💳 2. Fal.ai チャージ（Billing）ページを開く ↗
手順③：「+ Add key」を押してキーをコピー＆貼り付け キー発行ページ（Keys）で 「+ Add key」（または Create Key）を押し、出てきた英数字のキーを「Copy（コピー）」します。
あとはこの画面の上の入力欄に貼り付けて「✔ APIキーをiPhoneに記憶・保存する」を押せば完了です！
